# Python Learning Projects

A running collection of the Python exercises, small projects, and practice
problems I work through while learning the language. Everything here is written
by hand rather than copied — the goal is understanding each line, not just
getting a green checkmark.

## Why this repo exists

Learning happens in small pieces, and those pieces get lost if they live in
scratch files. This repo is where they go instead. Each folder is one problem or
project, kept with the reasoning behind it so it stays useful when I come back
to it months later.

## Structure

Each project lives in its own folder with the code and a short README covering
what the problem was and how the solution works.

```
.
├── caught_speeding/
│   ├── caught_speeding.py
│   └── README.md
├── <next_project>/
│   ├── ...
│   └── README.md
└── README.md
```

## Running the code

Everything here is plain Python 3 with no external dependencies unless a
project's own README says otherwise.

```bash
python3 caught_speeding/caught_speeding.py
```

## Conventions

- 4-space indentation, no tabs
- Double quotes for strings, used consistently within a file
- One folder per problem, each with its own README
- Solutions favor readability over cleverness — if a line needs a comment to be
  understood, it usually needs rewriting instead
